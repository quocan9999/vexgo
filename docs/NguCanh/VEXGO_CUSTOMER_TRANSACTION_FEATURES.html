Transaction mẫu phía Customer

Đặt vé một chiều

BEGIN TX lock/claim GheChuyenXe validate BangGia create DonGiaoDich create PhieuDatVe create Ve[] update trạng thái ghế recalculate tongTien COMMIT

Gửi hàng riêng

BEGIN TX lock ChuyenXe validate diemGui/diemNhan validate capacity create DonGiaoDich create PhieuGuiHang create HangHoa[] group theo LoaiHangHoa find đúng 1 BangCuocGuiHang / loại create ChiTietCuocGuiHang[] create LichSuTrangThaiPhieuGuiHang update tongTien COMMIT

Đặt vé + gửi hàng cùng chuyến

BEGIN OUTER TX lock ghế lock ChuyenXe create DonGiaoDich create PhieuDatVe + Ve[] create PhieuGuiHang create HangHoa[] create ChiTietCuocGuiHang[] create history recalculate tongTien COMMIT Bất kỳ bước nào fail => rollback toàn bộ

Payment callback

CALL GATEWAY (outside DB transaction) WEBHOOK: BEGIN TX check idempotency insert/update ThanhToan update DonGiaoDich create/update HoaDon update booking/shipment status nếu cần COMMIT

Đổi ghế

BEGIN TX lock ghế cũ lock ghế mới verify ghế mới còn trống release ghế cũ claim ghế mới update Ve.gheChuyenXeId COMMIT

Hủy vé có hoàn tiền

CALL REFUND GATEWAY (outside DB transaction) CONFIRM/CALLBACK: BEGIN TX update ThanhToan/refund state update Ve release GheChuyenXe nếu rule cho phép update DonGiaoDich COMMIT

Quy tắc triển khai cho agent

Frontend không phải source of truth

Frontend chỉ gửi lựa chọn. Backend phải tự tính fare, discount, capacity, total và snapshot áp dụng.

Không gọi gateway trong DB transaction

MoMo/VNPAY/ZaloPay, email, SMS, upload file phải ở ngoài transaction đang giữ lock.

Booking + shipment phải dùng cùng outer transaction

Helper shipment nhận tx từ checkout service; không tự mở transaction riêng.

Concurrency test phải chạy DB thật

Mock repository không chứng minh được row lock hoặc race condition. Nên có integration test trên MySQL.

Capacity và pricing là hai phép tính khác nhau

Capacity = SUM(soLuong); pricing weight = SUM(khoiLuong * soLuong).

Idempotency cho checkout/payment

Double-click, retry mạng và webhook retry không được tạo giao dịch trùng.
